# @markii/core

The framework-agnostic reference parser for [Markii](https://github.com/markii-org/markii) (`.mk.md`): CommonMark + GitHub-Flavored Markdown plus a generic directive syntax, parsed to an mdast tree and converted to a sanitized hast tree. Zero React dependency — component-agnostic by design, so any renderer (e.g. `@markii/react`) can consume its output.

See the [repository](https://github.com/markii-org/markii) for the format spec and the reference library as a whole.
