# @markii/pack

Component pack contract for [Markii](https://github.com/markii-org/markii): the `pack.json` manifest shape (`docs/packs.md`), namespace and engine rules, and hand-rolled validation. No React, no markdown parsing, no bundle loading — this package defines the contract that a later registry-loading slice builds against.

See the [repository](https://github.com/markii-org/markii) for the format spec and the reference library as a whole.
