Keep them wide rather than tall: each sits in a third of the table, so a
tall image makes the row enormous. Around 1200px wide is plenty, and a
dark-theme shot reads better against both GitHub themes.

Until a file exists, GitHub shows the image's alt text in its place, so the
table stays readable.
